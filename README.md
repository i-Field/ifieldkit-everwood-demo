# ifieldkit-everwood-demo
FieldKit AI — Everwood Candles

A premium, nature-inspired landing page concept for a fictional artisan candle brand, created as a demonstration project by FieldKit AI.

✨ Features

* Responsive layout for mobile and desktop
* Elegant, editorial-inspired visual design
* Product collection showcase
* Mobile navigation
* Interactive demonstration buttons
* HTML, CSS and JavaScript
* Designed for GitHub Pages deployment

🎨 Design concept

The visual identity combines warm cream tones, deep olive green, natural textures, soft candlelight and refined typography.

🛠️ Built with

* HTML5
* CSS3
* Vanilla JavaScript
* GitHub Pages

🚀 Deployment

1. Open the repository’s Settings → Pages.
2. Select Deploy from a branch.
3. Choose the main branch and the /(root) folder.
4. Save and wait for deployment.
5. Open the published URL provided by GitHub Pages.

⚠️ Demo notice

Everwood Candles is a fictional brand created for design demonstration purposes. Product descriptions, prices, reviews and contact details must be verified or replaced before commercial use.

The current demonstration does not process payments or submit real orders.
